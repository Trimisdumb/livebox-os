# V4 design decisions

Design read: a network administration workspace for home-network owners, using Orange-inspired contrast and practical equipment controls. ENERGY 2 / RHYTHM 2 / MOTION 1. This follows the user's supplied brand, navigation, accessibility and restrained-motion direction.

- Orange marks the current destination and the primary action because those indicate where the user is and what they can do next.
- Solid neutral surfaces separate administration from the wallpaper desktop and keep router output readable in both themes.
- The grouped navigation accommodates the requested network categories; a compact bottom navigation and searchable menu replace it on phones.
- The connection statement is the dashboard focal point because the first decision is whether to connect equipment or investigate a failure.
- The dashboard uses definition lists and equipment rows rather than equal metric cards, so unavailable measurements remain explicit.
- Segoe UI/Arial reuses the installed type stack, works offline on Windows/Linux, and keeps administrative forms legible without downloading fonts.
- Spacing separates connection summary, inventory and history; compact density reduces row spacing without reducing touch targets.
- Existing Lucide device/network/settings icons are retained for their literal meanings and license continuity; labels carry the navigation meaning.
- The existing independent SVG logo is reused; no new trademark, avatar, illustration or fictional network imagery is introduced.
- Motion is limited to existing interaction feedback; reduced-motion mode disables it. There are no perpetual animated status indicators in the new workspace.
- Status uses text as well as color. Empty and unavailable values never become invented rates, device counts or security scores.

Verification and the Anti-Slop delivery gate are recorded in [V4 validation](V4-VALIDATION.md). This document records design intent, not a claim that every V4 roadmap feature is implemented.
