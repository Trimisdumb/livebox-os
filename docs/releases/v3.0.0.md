# Livebox OS v3.0.0

**Prepared release notes — not published yet.**

Free, local-first administration for Orange Livebox 5 and the optional TP-Link Archer AX58 V1.0. Includes a desktop UI, real router reads, a coordinated double-NAT wizard, topology, monitoring, diagnostics, application backups and read-only SMB2/3 support.

## Compatibility and verification

- Real hardware checks: Livebox 5 and Archer AX58 V1.0, firmware **1.5.2 Build 20250812 rel.38324(4555)**.
- A temporary double-NAT operation was created, read back and deleted with explicit owner approval. Existing rules were preserved. Public reachability was not tested.
- Tests for coordinated updates, conflict detection, partial failures, rollback and SMB path protection are isolated tests, not a claim of live hardware fault-injection.
- Public candidate dependency updates and clean-clone checks are recorded in [VALIDATION.md](../VALIDATION.md) and [PUBLICATION-AUDIT.md](../PUBLICATION-AUDIT.md).

## Install

Download the source archive, extract it, open a terminal in its root and run:

```sh
docker compose up -d --build --wait
```

Open http://localhost:8097, approve the pairing reference from your host terminal and create your own account. See [INSTALL.md](../INSTALL.md). No administrator or router password is included.

## Upgrading private installations

Back up application data and the persistent volume. Preserve the existing project name, volume and private deployment configuration. Sessions must be reopened after restart. Do not run `down -v` on an existing deployment.

## Limits

TP-Link Wi-Fi writes and its firewall API are not enabled. A real authenticated SMB share has not been validated. Other router models/firmware are not claimed compatible. NAT rules do not prove public reachability.
